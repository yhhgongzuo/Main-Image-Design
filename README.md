# Main-Image-Design 🎨

> 上传几张产品图，AI 带你把风格和文案一步步定下来，一次出**一套六张电商主图**：1 张白底首图 + 5 张副图。

不用自己写提示词，不用会 PS，全程就是聊天——AI 问你几句、你回几句，最后拿到六张能直接上架的正方形图。默认按亚马逊美国站的习惯出图（首图白底、英文文案），想改成中文或别的语言说一声就行。

**⬇️ 一键下载安装包：[main-image-design.zip](https://github.com/yhhgongzuo/Main-Image-Design/releases/latest/download/main-image-design.zip)**

## 🎯 这个 Skill 能帮你解决什么

- 把「阿辉的主图设计」装进你的 AI Agent，装完永久可用
- 会用一句话让 AI 出一整套六张电商主图，不用自己写提示词
- 知道该选哪个平台、哪个模型，少烧额度、少走弯路

**适合谁**：做电商、手里有产品要出图、但不会 PS、也不想研究复杂 AI 工具的人。看完就能自己跑一套。

## 🖥️ 支持平台

| 平台 | 建议 | 生图模型 | 思考设置 | 实测情况 |
|---|---|---|---|---|
| **Codex** | **最强推荐** | 内置 GPT 生图，不用另外接 API | GPT-6.1 Sol + 高 | 一步到位，出图最稳 |
| 豆包工作 | 能用，建议换模型 | 可以自己接生图 API，换成 GPT Image | 高 / 深度思考 | 自带生图也能出图，但产品上的文字容易变形 |
| WorkBuddy | 不建议 | 需要自己选 | 看实际界面 | 思考模型能力弱，生图也弱，出图不稳定 |
| 其它 Agent | 能跑，看你怎么配 | 必须自己接 GPT Image API | 高 | 配得好能用，配不好就是白折腾 |

> 💡 **最关键的一条：只要不是 Codex，都建议你自己接一个 GPT 的 Image 生图模型 API。** 生图模型直接决定画面质量和图上文字会不会变形，这一步别省。所有能接通 Agent 的平台，都建议自己配一个 GPT Image 生图模型。

> 💡 **思考模型怎么选：** 建议 **GPT-6.1 Sol + 思考程度「高」**。不要设成低或中——思考深度会直接影响最终出图效果。这个组合实测下来性价比最高；预算充足、能力够的，可以上 Astra。

> 💡 **必须切换到「工作模式」**：不管是海外的 Codex，还是国内的豆包、WorkBuddy，都要先切到能接管电脑、执行任务的「工作模式」再运行。普通对话模式只能聊天，技能不会生效。

## 📦 安装与使用（三步上手）

核心就是：**下载安装包 → 丢给 AI 装好 → 发图下指令**。

### 第一步：下载安装包

**[main-image-design.zip](https://github.com/yhhgongzuo/Main-Image-Design/releases/latest/download/main-image-design.zip)**

### 第二步：上传安装包到 AI 对话框，输入安装指令

把 ZIP 直接上传（或拖进）对话框，**不要手动解压**，然后附上这句：

```text
帮我安装这个技能，然后告诉我怎么使用。
```

### 第三步：新开窗口，上传多角度产品图，发送下面这句

```text
用阿辉的主图设计
```

说「用阿辉的出图设计」「帮我做电商主图」也一样能触发。

然后剩下跟着 AI 走：它会带你补全产品信息 → 选风格 → 确认六图方案和文案 → 生成六宫格小样 → 你确认没问题 → 出六张独立高清图。

**中间的确认节奏**：

1. 先看完整的六图方案表（每张图的卖点、上图文案、场景），单独回复 `确认生成`
2. 看六宫格小样，整体没问题回复 `继续做高清图`；有问题直接说，它改这张小样再发给你看
3. 最后拿到六张独立图，哪张要改就报编号 + 说人话（或把那张图发回来）

## ⚠️ 最重要的一条提醒：产品图一定要多角度

> 💡 **只传一张正面图，出图一定单调，而且容易画错。**
> AI 只能看见你给的角度。你只给正面，六张图就会围着正面打转，侧背面的结构和细节全靠它猜。

**你希望买家看到的每个细节，都要自己拍进去：**

- 正面、侧面、背面、底部
- logo、标签、印刷文字的近距离特写
- 接口、按键、开关、开合结构
- 材质和纹理的近拍
- 配件、包装盒、赠品
- 真实使用场景（有就拍，很有用）

一套图建议准备 **5～10 张不同角度**，手机拍清晰就行，不用精修、不用抠背景。这一步偷懒，后面就会一直觉得「不像我的产品」，还得反复改。宁可多拍两张，也别只给一张。

另外 AI 通常会问你 3～5 个问题（尺寸、用途、最想突出的卖点、买家收到什么）。知道就填，不知道就回「没有，按图做」，不会卡住流程。

## ⚠️ 注意事项 & 常见问题

**装完了，说「用阿辉的主图设计」却没反应？**

先把聊天窗口重开一次，有的平台要重载才认新技能。还不行，就回到刚才那个对话，直接问它「技能装在哪、为什么没被调用」，让它自己检查。多半是技能目录或依赖没装好，可以让它按 `INSTALL.md` 重新检查一遍。

**图上的英文能改成中文吗？**

能。在方案阶段直接说「改成中文版」或「改成日语版」，它会把标题、副标题、标签、尺寸全部重写一遍，再等你确认。确认过的文案才会画到图上，所以改完记得再看一眼。

**图上的文字变形、糊了怎么办？**

多半是生图模型的问题，不是技能的问题。换成 GPT Image 类模型重做，一般就好了。高清阶段它本身会修模糊和文字变形，但不保证一次全修好；还不满意就报编号让它重做那一张。

**我的产品不是亚马逊的，能用吗？**

能用。默认按亚马逊美国站的习惯出图（首图白底、英文文案），你做别的平台也可以拿它出素材，需要改语言说一声。它不会去搜竞品，也不会硬套爆款模板，卖点都来自你给的产品资料。

**一套图大概花多少额度？**

正常一套 **7 次生成**（1 次小样 + 6 张高清）。中途改小样不算高清额度。具体扣多少看你平台怎么计费，作者这边看不到，也不承担。

**安装时提示报错怎么办？**

大多数情况是环境缺依赖（Node 20+、Python 3.9+、Pillow）。按 `INSTALL.md` 让 AI 先补环境再安装，重新说一次「安装」即可。包内提供宿主能力发现与自行适配流程，缺什么会明确告诉你，不会硬说装好了。
