# 国内电商分支：满版营销与真实商业摄影

仅 `design_profile=domestic` 时阅读。国内默认高密度营销文案、满版图文和真实商业摄影；用户明确风格与平台角色优先。本文件的国内要求优先于共用资料中偏克制、少文案或仅展示描述的默认，不向亚马逊分支传播。保留原有产品依据、方案确认、附件隔离、六宫格、高清及用户验收流程。

## 平台先于设计

- 第一轮补资料时，若初始需求未明确发布／上架平台，合并询问：“这些图片准备发布／上架到哪个平台？例如淘宝、天猫、京东、拼多多、抖音或亚马逊。”已明确不重复问；其他资料齐全也只问这一项。知道平台后才 `init`，不要先按语言猜平台。
- 用户说没有产品参数，不代表已回答平台。未回复继续等待；只答“国内”但未说平台，可简短补问具体平台。用户明确要求“国内通用”“还没定，先做国内通用”才使用 `国内电商通用`，说明这是通用设计方案。
- 平台决定分支，图片语言独立：淘宝英文仍是国内版，亚马逊中文仍是原亚马逊版；聊天语言、产品包装文字、参考图语言均不决定市场。中途换语言只换文案，不换平台或风格。
- 淘宝、天猫、京东、拼多多、抖音、快手、小红书电商、1688、微信小店等走国内版；天猫国际／京东国际按面向国内消费者处理。小红书等要区分商品上架图与笔记封面，本技能此分支处理前者。
- 本次海外实现保持原 Amazon US，不把 Temu、TikTok Shop、Shopee 等自动当亚马逊。遇到其他海外平台说明当前支持范围，先澄清能否按亚马逊参考方案策划，不能声称符合该平台要求。自定义国内平台需填写 `design_profile=domestic` 和真实 `platform_basis`。

## 国内默认：高密度、强营销、满版

用户未指定风格时，国内营销内容图主动组织丰富文案、醒目商品、实体空间、辅助细节和相关设计元素。不是仅在简约构图上加几个胶囊标签。避免整套“单件商品＋两句大字＋大片渐变背景”。用户没有提供文案时，AI负责创作完整营销文案，不要求用户自己补齐，也不因此减少内容。

满版是画面空间有内容承担：文字丰富时以层级和分组组织；文字较少时，以足够丰富的真实场景、人物情境、商品细节或相关视觉内容补足。不能文案少、场景少、辅助内容也少。允许必要字距、行距和模块间隔，不能把大片空背景解释成高级感。商品和核心利益在手机缩略图中清楚，小字号内容供放大细读，必要条件必须可读。

按任务选择文案主导、场景主导或图文共同主导的满版方式。首图商业吸引最强，其他营销图同样饱满，但改变任务、景别和信息安排。无营销／白底角色不套此密度；用户明确极简、插画、卡通等方向时按其要求。

## 主动创作完整文案：在原有方案确认前完成

先理解产品，再创作文案、分配六图内容和设计布局。用户仅给三两句话时，不把它们当作全部文案上限；围绕本品特点、品类语境、审美和适用情境，主动补写有营销吸引力的内容。不能只增加“细节展示”式标注，也不能六张反复使用同一口号。

| 层次 | 写什么 | 落在现有字段 |
|---|---|---|
| 主标题 | 本张最重要的特点、主题或购买吸引点 | title |
| 副标题 | 解释标题，补充另一层意思 | subtitle |
| 营销短句 | 与本品相关的情境、审美、生活方式或使用期待 | extra_copy |
| 小字号卖点组 | 从已知特点提炼不同侧面，多个短标签成组 | extra_copy |
| 解释和细节标注 | 对应局部展示、已知差异及真实结构 | extra_copy |
| 底部信息 | 总结主题、已知规格、组合特点或真实权益 | extra_copy |
| 必要备注 | 确有条件需要说明时填写 | extra_copy |

主副标题之外，默认主动安排多条辅助短文案及一组小字号卖点；首图可以组合身份信息、标题、补充短句、卖点组、细节标注和底栏。普通卖点图也不止三两句话。按内容及场景调整，不设固定字数或标签数量，不为达到数量编造产品能力。信息不足时，用适合本品的营销情境表达配合可见细节、真实空间填充画面。

允许创作表达，不允许创作产品事实：
- 可见结构、外观、包含物等依据image/user事实编写；把事实变成自然营销语言，不凭常见行业习惯推断本品能力。
- 可以主动写不承诺性能的品类情境、审美和主题短句，例如美妆的“为日常妆容，多一点灵感”，家居的“让日常空间，更合心意”。示例仅说明表达类型，按本品重写，避免六张堆同样的泛用口号。
- 国内 `source=generic` 可记录上述创意文案的适用语境及非性能边界，source_ids=[]，evidence说明“AI创意表达，不构成产品功效或参数依据”；相关panel.fact_ids引用其ID。不得冒充用户提供或已验证事实。国内此范围优先于共用产品文档中仅展示描述的保守默认，亚马逊范围不变。
- 功效、持久性、安全、成分、具体用法、尺寸、承重、防水、认证、专利、销量、价格、赠品、服务等需本品资料；“温和不刺激”“轻巧便携”“精准不失手”等也不能仅因常见就自动添加。
- 情境文案不能隐含未知用途。原料、植物、水、人体比例和道具同样可能暗示成分、能力或尺寸，选择与本品依据相容的内容。

完整上图文案使用现有title/subtitle/extra_copy，不增加问卷或数据结构。extra_copy按阅读顺序逐条填写真实上图文字，不把“辅助卖点：”等内部角色名称误写进去；typography说明各组的层级和组织。所有新增营销短句、小卖点、说明和备注一并进入原有六图确认表。确认后生图逐字执行，禁止让绘图模型临场编写宣传。无资料／让AI发挥不跳过原有方案确认。

## 真实摄影优先，图形辅助组织

无明确参考时默认采用商业摄影质感的商品、人物、展台和环境。用户提供整体风格参考后，以其选定背景、图形、材质、光影强度和装饰密度为准；摄影商品可以结合参考中的图形或特效背景，真实产品与丰富背景同时成立。先确定参考意图再选择规则，不向已选强光效风格叠加“光效少量使用”或“抽象光带不作背景”的相反要求。产品原有材质、结构和事实不随风格改变，人物仍按适用景别自然呈现。

- 商品：原有结构、颜色和材质外观保持，塑料不能为显贵改成玻璃，壳体和刷毛／织物等表面应有不同反射及纹理。
- 展台：选可识别的实体材料，写关键边缘、厚度、表面与接触阴影。例如哑光烤漆台的柔和表面、可信边缘和瓶底落影；不要只写“高级展台”。不固定全品类大理石或奶油台。
- 背景：保留可辨识环境或真实棚拍空间，景深服务主体，不把所有背景都变成同一种模糊散景或渐变。场景不能挤占全部文字阅读区。
- 人物：需要时采用自然真人摄影观感，肤质、姿态、视线和接触合理；保留场景气氛，不默认剪影或过度磨皮。先确定人在做什么，再决定姿势。
- 图形：底板、细线、色块、标注和局部小窗用于分组、阅读和注意力，不要求每条文字都包胶囊。少量光效可强化气氛，不取代真实内容。

人物与事实分开判断：情境人物可以营造已知品类的生活环境，不等于展示使用结果；真实接触／操作动作须确认用途和方法；试色、妆效、前后对照及性能结果需要对应依据。缺妆效资料时，可用梳妆情境配独立商品主视觉，不必一律降成剪影，也不能自行安排未知涂抹部位。

无风格参考时优先用相关场景、商品细节和情境补空间；整体参考时优先保留已选参考的空间组织与背景丰富度，是否引入真人或其他场景服从本品方案，不能为求变化擅自换成另一种视觉风格。不重复摆许多同款假装丰富；多视图和局部窗应明确属于同件商品，不暗示套装或赠品。

写实执行采用[商业视觉决策中的 V3.6.1 实拍观感规则](commercial-art-direction.md)：品牌色与环境自然色分开，人物按景别保留自然细节，材质依原图，不把柔光处理为统一平滑高光。逐图明确同一空间摄影或独立特写叠加，关键摄影与物理关系进入实际提示词及高清任务；满版不要求把全部环境染成品牌色。

## 信息框架与六图分工

营销首图的信息框架可由身份识别、标题、商品、侧边卖点、辅助展示及底栏围合形成，不强制顶部胶囊、描边外框和固定高度底栏。框架是信息组织，不是六张套同一外形。无活动资料用本品特点、已知规格或主题承接；真实活动价格须注明金额、规格及条件。不迁移参考中的功效数字、专利、认证和权益。

六张先回答不同购买问题，再安排视觉：核心吸引、结构依据、真实情境、使用／体验、选择信息／剩余疑问、商品识别。默认第6格白底，角色可按平台及事实调整。有依据才安排试色、用法、尺寸、配方、对比或内部结构；缺资料换选题，不用抽象弧线勉强解释未知性能。不同构图仍需增加新的理解，不把“多头”“双头”“一支多用”当作三种独立购买理由。

| 品类 | 可组合的真实视觉内容 | 事实边界 |
|---|---|---|
| 美妆／个护 | 真人情境、梳妆空间、包装与刷头微距、已知试色和质地 | 用法、妆效、成分和功效需本品依据 |
| 食品／饮料 | 餐桌、实物切面、已知原料、盛装与食用情境 | 不增加未知成分、份量、产地或功效 |
| 数码／家电 | 实际使用空间、操作局部、真实界面、结构细节 | 不增加未知接口、内部、防水或性能 |
| 工具／工业品 | 正确作业、真实工位、部件和实际配件 | 不虚构配件、适配、参数或错误操作 |
| 家居／收纳 | 实际空间、已知容纳内容、材质和结构细节 | 容量、尺寸、承重和安装需依据 |
| 服装／鞋包／配饰 | 真人搭配、面料、工艺、多角度及选择信息 | 保留真实版型、材质、比例与包含物 |

## 参考提取与整套视觉规范

参考图按用户指定范围提取：文案有几层、标题与小字如何配合、哪些内容填充空间、实体材质与光影、场景如何承接商品。借鉴信息组织和完成度，不把参考功效、认证、品牌、价格当本品事实；跨品类不直接复制植物、色彩和道具。参考仍只分析，不进入生图附件。

在 `style-analysis.visual_system` 保留五个现有非空文本字段，并与完整方案一起展示，无新增确认：

| 字段 | 国内约定 |
|---|---|
| colors | 主色、辅助色、强调色及用途，产品颜色不变；各张可改变明暗和面积，不逐张随机跳色 |
| typography | 字体气质与字重；主副标题、营销短句、小卖点、正文和备注的层级；标题醒目，小字成组可读，避免所有内容都放大 |
| components | 适合本品的信息底板、标签、标注、小窗及框架语言；同功能一致，不必全部胶囊，也不要求每张都出现 |
| spacing | 安全边距和对齐原则；保留阅读间距，避免大片空背景；比例只作参考，不机械锁死所有局部 |
| photography | 实体材质、自然光影、修图气质、真人及场景处理；可改变景别、机位和场景，保持真实物理关系 |

统一色彩角色、字体层级、组件语言和摄影气质，允许变化构图、文字排列、商品大小、背景深浅和场景。高级感不等于少字或少元素。字号相对比例可作起点但不固定照抄，同级一致且必要小字可读；实际工具不保证精确字体和像素字号。

`creative_summary`只写简明总体方向；`transferable`写通常4–6条选定的关键视觉特征，国内编译完整带入一次；`visual_system`补充执行规范，避免重复前两者。形态、材质、疏密、明暗面积、前后层次及图文关系按参考实况提炼，不能只有“高级、科技、紫色”等概括词。`do_not_copy`精简记录迁移边界，`set_rules`保留分析约束，不把全部观察和流程说明发给模型。关键特征在适用逐图方案落实，白底和已确认情境按其角色处理。

## 逐图落地与生成前设计检查

复用现有字段，不增加表单：
- creative_direction：本张独特主题和视觉方法，短句即可。
- presentation：实际商品展示、人物情境或辅助细节；composition：信息分区、商品与场景关系、剩余空间由什么填充，汇总必要decoration/title_position等决定。
- typography：完整文字层级、卖点组及说明的排列，写入必要文字位置与图文关系；visual_hierarchy：第一眼、第二眼、小字细读顺序。
- lighting_materials、scene_physics：仅写当前图关键材质、光线、接触及受力；angle依据原图。
- 其余既有字段照常填写用于分析与审核，避免同义反复；关键执行决定不能只藏在focus/decoration/text_product_relation/rhythm等字段中。

在现有creative_review的content、typography、composition、benefit_expression、rhythm、photography及reference_adaptation等notes中完成生成前判断：
1. 无用户文案时，是否主动创作了营销短句、多条辅助文案及小字号卖点，而非只留主副标题？小字有作用，不重复同一卖点。
2. 每张营销图是否由文案、商品、真实场景或细节共同形成满版？若只有两句大字、单商品和空背景，先完善方案；白底及用户明确风格例外。
3. 商品和标题在缩略图中可辨，小字层级清楚，必要条件可读；不靠无限缩小文字填内容。
4. 台面、环境、人物与材质是否具体可信？是否仅用透明板、弧光、光晕换背景？场景动作是否有依据？
5. 六图是否分别增加信息、改变任务和景别，且保持整套气质？
6. 完整上图文字及关键场景、布局决定是否进入实际执行字段，与已确认方案一致？
7. 逐条对照transferable：所选参考的关键特征是否进入实际编译提示词、适用各图是否落实？full_style是否保留背景及装饰强度，selective是否越界，quality_only是否误搬配色？是否混入相反的默认要求？在creative_review的reference_adaptation中记录保留点和角色例外；脚本能确认传递字段，视觉语义仍由宿主判断，不宣称程序证明风格相似。

以上是生成前策划，不增加生成后AI视觉检查、自动重试或新的确认关卡。六宫格分摊像素有限，不靠小样OCR恢复小字；高清继续传入完整确认文案，不承诺小样或高清一次完美渲染全部细字。

## 国内执行提示词：详细分析留内部

国内编译走独立domestic-brief，亚马逊沿用原编译路径。输出任务、商品依据、整套规范、逐图画面与完整文案、关键边界即可。平台规则调研过程、风格观察全集和重复政策留内部，不发给绘图模型。

锁定商品身份、图片角色、全部文案及关键风格与场景；允许局部对齐、语义断行和合理叠压。总体方向、选定特征和视觉规范各写一次；逐图presentation写主体及行为，composition写布局与风格元素落点，typography包含必要主次，lighting_materials及scene_physics只补本图关键关系，不在多个字段重复同一句话。编译省略重复的目的、创作方向和阅读主次长段，不重复整篇摄影通则；必要决定务必写进上述执行字段。

一般六图任务以约2400–3200字符作为执行稿软目标，整套风格说明通常约500–700字符；逐图再补不同落点。字符不是token或注意力权重，不强制凑字、不自动截断。复杂产品或较多确认文案可超出；先删通用套话及语义重复，不能删关键参考特征、必要产品约束或完整文案。长度控制主要在策划时完成，编译只去除完全重复条目，不声称能自动理解和压缩语义。

## 工作表与平台依据

国内 `platform_rules` 必填：

```json
{
  "status": "design_assumption",
  "basis": "具体平台、类目、图片用途、已有规则依据及未核对项；以下位置安排为本次设计假设，不是已核实平台条款",
  "first_panel_white_background": false,
  "first_panel_marketing_copy": true,
  "white_product_panels": [6]
}
```

已核对真实适用规则才用 `confirmed`；规则有疑问时按需查官方资料，不搜索竞品，不把模板截图当规则或销量证据。普通设计可显式记录 `design_assumption`，不要为填写confirmed虚构来源。特殊类目要求优先；实际发布数量、位置、文字或价格限制按目标平台及类目核对。

白底商品图编号可调整，`[]` 需在basis说明本次不含白底图原因；首图角色必须与编号一致。如果首图不允许营销文案，`first_panel_marketing_copy=false`。所有白底商品图均为 `background=#FFFFFF, product_only=true, title="", subtitle="", extra_copy=[]`，无框架／徽章／横幅；不把有营销字的白色海报误标为白底商品图。

其余 blueprint 字段与亚马逊相同：完整当前语言文案、fact_ids/source_ids、角度依据、商业视觉三项、不同buyer_question、全局review及creative_review均保留。`knowledge_basis={mode:"local",application:"国内策略如何依据本品事实落地"}`。每格只填确需产品证据；`copy_locale=inputs.locale`。价格及数字也进入已确认文案并绑定事实。

小样修改、换语言和六张高清始终使用已确认角色与同一visual_system。国内首图不会再被强制改白底，第六张也不会因为编号是6就丢失白底约束。修改图片角色／上架平台需重新策划与确认，不能在普通文案修改中绕过。原有两次确认、单次生成、无自动修复、文件基础校验和用户验收流程保持不变。
